# Divulgador

Letreiro animado para festas e eventos, no estilo dos antigos programas de banner do DOS.

**Abrir:** https://srleandrosantarita-star.github.io/divulgador/

## Instalar

- **Android:** abra o link acima no Chrome, toque no menu **⋮** e escolha **Instalar app** (ou **Adicionar à tela inicial**).
- **Windows:** abra o link no Edge ou no Chrome e clique no ícone de instalar na barra de endereço, ou use a pasta do aplicativo com o atalho da Área de trabalho.

Depois de aberto uma vez, funciona sem internet: as fontes vêm junto com o aplicativo.

## O que tem

- 162 fontes, 38 efeitos de letra, duas linhas de texto com cores próprias
- 58 fundos animados e 28 bordas de festa
- 34 modelos prontos (festas infantis, datas comemorativas e eventos)
- Piloto automático com 21 transições
